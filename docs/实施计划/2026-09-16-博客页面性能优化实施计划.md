**目标:** 优化博客页面加载速度,消除卡顿,提升用户体验,目标实现首屏加载时间减少 50%,构建时间减少 60%

**架构:** 采用构建时预计算 + 静态数据缓存 + 客户端组件懒加载策略。将运行时计算迁移到构建时,减少客户端 JavaScript 负载,优化资源加载优先级。

**技术栈:** Astro 5, React 19, TypeScript, Node.js, Sharp (图片处理)

**问题背景:**
当前博客页面存在以下性能问题:
1. 每次构建时重复计算64篇文章的字数统计 (耗时显著)
2. 客户端实时调用 GitHub API 获取最新提交时间 (网络延迟)
3. 多个 React 组件使用 `client:idle` 和 `client:load`,JS bundle 过大
4. KaTeX CSS 从 CDN 加载,阻塞首屏渲染
5. 构建产物 330MB,图片未充分优化

## Task 1: 缓存文章统计数据

**目标:** 将文章字数统计结果缓存到 JSON 文件,避免每次构建重复计算

**Files:**
- Create: `scripts/cache-post-stats.ts`
- Create: `src/data/post-stats.json`
- Modify: `src/hooks/usePostsData.ts`
- Modify: `package.json`

**Interfaces:**
- Consumes: `getCollection("blog")` from Astro, `getReadingStats()` from `@utils/readingTime`
- Produces: 
  - `PostStatsCache` 类型: `{ totalWords: number; avgWords: number; postCount: number; lastUpdated: string }`
  - `cachePostStats()` 函数: 生成缓存文件
  - `getPostsData()` 修改后优先读取缓存

### 步骤:

- [ ] **Step 1: 创建缓存生成脚本**

创建 `scripts/cache-post-stats.ts`:

```typescript
import { getCollection } from "astro:content";
import { getReadingStats } from "../src/utils/readingTime";
import fs from "node:fs/promises";
import path from "node:path";

interface PostStatsCache {
  totalWords: number;
  avgWords: number;
  postCount: number;
  lastUpdated: string;
}

async function cachePostStats() {
  console.log("🔄 开始计算文章统计数据...");

  const posts = await getCollection("blog", ({ data }) => !data.draft);

  const totalWords = posts.reduce((acc, post) => {
    const { count } = getReadingStats(post.body || "");
    return acc + count;
  }, 0);

  const postCount = posts.length;
  const avgWords = postCount > 0 ? Math.round(totalWords / postCount) : 0;

  const cache: PostStatsCache = {
    totalWords,
    avgWords,
    postCount,
    lastUpdated: new Date().toISOString(),
  };

  const dataDir = path.join(process.cwd(), "src", "data");
  await fs.mkdir(dataDir, { recursive: true });

  const cachePath = path.join(dataDir, "post-stats.json");
  await fs.writeFile(cachePath, JSON.stringify(cache, null, 2), "utf-8");

  console.log("✅ 文章统计数据已缓存:");
  console.log(`   - 文章总数: ${postCount}`);
  console.log(`   - 总字数: ${totalWords.toLocaleString()}`);
  console.log(`   - 平均字数: ${avgWords.toLocaleString()}`);
  console.log(`   - 缓存文件: ${cachePath}`);
}

cachePostStats().catch((error) => {
  console.error("❌ 缓存文章统计失败:", error);
  process.exit(1);
});
```
