## 目标与边界

依据用户确认的方案，减少客户端重复工作、原始封面传输及构建统计重复计算。保留布局、霞鹜文楷、星空光束、小乐魂、毛玻璃、轮播速度与悬停效果；不承诺未经实测的提速比例。不部署、不提交 Git。

## 实施切片

1. 记录当前构建、类型检查及页面资源基线；使用现有 Chrome 检查代表页面。
2. 文章交互：在页面切换时清理滚动监听及目录观察器，RAF 合并更新；代码块结构在 rehype 构建阶段生成；Mermaid 渲染去重。相关文件：`src/layouts/BlogPost.astro`、`src/utils/rehypeCodeBlocks.ts`、`src/components/MermaidRenderer.astro`。测试覆盖行号、代码原文、特殊代码块与重复处理；浏览器检查文章切换、复制、折叠及目录。
3. Echo 封面：在 Astro 服务端准备图片，传递响应式资源给 React；避免额外全量预加载，保持循环轮播提前加载的安全余量。相关文件：`src/pages/echo/index.astro`、`src/features/echo-carousel/data/covers.ts`、`src/features/echo-carousel/components/EchoCarousel.tsx`。验证每张图片的源文件、尺寸及输出；浏览器检查响应式选择、布局与完整轮播资源。
4. 动画与统计：隐藏时停止星空无效 RAF，离屏轮播暂停并避免恢复跳跃；生产构建复用文章统计、开发模式重新计算。相关文件：`src/components/core/AmbientBlogBackground.tsx`、`src/features/echo-carousel/components/InfiniteSlider.tsx`、`src/hooks/usePostsData.ts`。对生命周期调度与缓存行为运行定向单元测试，并检查页面恢复。
5. 运行 `pnpm check`、`pnpm build`、`pnpm perf:check` 及上述定向测试；使用生产页面验证连续导航、Mermaid、代码块、轮播和主题。记录实测数据、验证限制与必要文档。

## 风险与回退

- 图片采用高质量或无损编码，并保留原始资源；无法确认画质的候选不启用。
- 构建阶段代码块结构须保持原代码文本及 class 不变，避免影响复制与 Shiki。
- 动画仅调整不可见时的计算；不改可见帧率、轨迹或清晰度。
- 缓存限制在构建进程，不增加手动更新数据文件步骤。
- 单项验证出现退化时撤销该项改动，保留其他通过验证的优化；不使用破坏性 Git 命令。
