# 专栏使用说明

专栏用于将一组有连续关系的系列文章集中展示。专栏只是文章的额外聚合视图，不会改变文章本身的归属：加入专栏的文章仍然会出现在全部文章、首页最近文章、文章归档、标签页和 RSS 中。

## 创建专栏

在 `/home/abeltomato/workspace/projects/AbelTomato.github.io/src/features/columns/data/columns.ts` 中增加专栏定义：

```ts
{
  slug: "max-flow",
  title: "最大流算法",
  description: "从 Edmonds-Karp 到 Dinic，记录最大流算法的学习过程。",
  order: 1,
}
```

字段说明：

- `slug`：专栏的稳定标识，同时用于生成 `/columns/{slug}/` 地址；
- `title`：专栏展示标题；
- `description`：专栏描述；
- `order`：专栏列表中的排序值，数值越小越靠前。

## 将文章加入专栏

在文章 frontmatter 中增加 `column`：

```yaml
---
title: "文章标题"
description: "文章描述"
pubDate: "2026-09-15"
tags: ["示例"]
column:
  slug: "max-flow"
  order: 3
---
```

字段说明：

- `column.slug` 必须与专栏定义中的 `slug` 完全一致；
- `column.order` 表示文章在专栏中的顺序，从 `1` 开始；
- 同一专栏内的 `order` 不能重复；
- `column` 是可选字段，未设置时文章就是普通文章；
- 当前版本一篇文章最多属于一个专栏。

## 访问地址

- `/columns/`：专栏列表；
- `/columns/{slug}/`：指定专栏的文章列表；
- `/blog/{article-id}/`：文章原有详情地址，不会因为加入专栏而改变。

## 发布前检查

```bash
cd /home/abeltomato/workspace/projects/AbelTomato.github.io
pnpm run check
pnpm run build
```

如果文章引用了不存在的专栏，或同一专栏内出现重复顺序，构建会失败并报告对应文章和专栏信息。
