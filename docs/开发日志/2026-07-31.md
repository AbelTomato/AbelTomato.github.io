# 开发日志：动态背景与悬浮组件频闪排查

**日期：** 2026-07-31  
**状态：** 已完成本地诊断能力与构建验证；永久修复等待线上 A/B 对照结果。  
**相关合并提交：** `ccea423 Merge branch 'diagnose/render-flicker'`

## 问题现象

页面存在动态 Canvas 星空、SVG 光束和多个固定/悬浮交互组件。滚动或触发普通 hover 后，动态背景与悬浮组件可能同时出现频闪。

该现象的关键特征是：不是某一个轮播或悬浮组件单独失效，而是多个视觉层在同一时间发生异常。因此排查范围从单个组件扩展到页面级合成、重绘与栅格化过程。

## 已确认的事实

1. 生产构建可正常完成：`pnpm run build` 成功，Astro 共构建 101 个静态页面。
2. 当前项目采用 Astro 静态站点与 React 客户端组件；动态背景实现位于 `src/components/core/AmbientBlogBackground.tsx`。
3. 背景由两类持续动画组成：
   - Canvas 星空：`requestAnimationFrame` 持续清屏并重绘；
   - SVG 光束：Framer Motion 持续驱动多个路径的 `pathOffset` 与 `opacity`。
4. 页面还有固定定位元素、hover transform/filter/transition，以及可能使用 `backdrop-filter` 的视觉层。这些特性会增加浏览器合成层与纹理重新栅格化压力。
5. 图片请求命中 `200 OK (from disk cache)` 时，不能据此判断为网络下载造成持续闪烁；该信息表明浏览器已从磁盘缓存读取资源。
6. 已为线上复现增加 URL 驱动的渲染对照模式；没有 `render-test` 参数时，正式页面行为保持不变。

## 当前推理

### 高概率方向：页面级合成/栅格化不稳定

Canvas 每约 42ms（约 24 FPS）执行整屏清空与重绘；同时 SVG 光束在独立动画时间线上变化。若滚动、悬浮动画、固定层或 backdrop 采样引发合成层失效/重建，浏览器可能在一帧内显示未完成更新的纹理，从而表现为背景和悬浮组件一起频闪。

这是一项高概率推断，**尚未通过 GitHub Pages 同域 A/B 结果确认**。

### 已降低优先级的方向

- 单一轮播组件逻辑：现象可由滚动和普通 hover 触发，且表现跨多个视觉区域；
- 图片持续网络加载：已观察到磁盘缓存命中，不符合持续网络下载的典型特征；
- 纯生产构建失败：本地生产构建通过。

上述方向不是绝对排除，只是当前证据不足以支持其为主因。

## 已实施的诊断能力

### `src/layouts/BaseLayout.astro`

读取 URL 参数 `render-test`，写入 `document.documentElement.dataset.renderTest`，并提供仅诊断时启用的全局样式开关：

| 参数 | 对照目的 | 行为 |
| --- | --- | --- |
| `no-background` | 判断背景是否为必要条件 | 隐藏动态背景容器 |
| `no-backdrop` | 判断 backdrop 采样是否参与 | 禁用全部 `backdrop-filter` |
| `no-hover-effects` | 判断 hover 合成变化是否参与 | 禁用 transition、hover filter 与 transform |

### `src/components/core/AmbientBlogBackground.tsx`

增加背景专用诊断：

| 参数 | 对照目的 | 行为 |
| --- | --- | --- |
| `static-background` | 区分背景静态层与动画重绘 | 首次绘制星空后停止 Canvas 更新，并隐藏 SVG 光束动画 |
| `no-svg` | 区分 SVG 光束与 Canvas 星空 | 保留 Canvas，仅停止 SVG 光束动画 |

背景容器新增 `data-ambient-background`，使 `no-background` 可精确定位该层。

## 线上验证步骤

部署到 GitHub Pages 后，在**同一页面、同一浏览器、相同操作**下分别测试下列 URL。每组均先硬刷新，然后连续滚动 20–30 秒并多次触发悬浮组件。

1. 默认页面：无 `render-test` 参数；
2. `?render-test=no-background`；
3. `?render-test=static-background`；
4. `?render-test=no-svg`；
5. `?render-test=no-backdrop`；
6. `?render-test=no-hover-effects`。

每组记录：是否频闪、背景是否随悬浮组件一起闪、首次出现时间、滚动/hover 哪种操作可触发、浏览器与硬件加速状态。

## 结果判定规则

- `no-background` 或 `static-background` 消除问题：背景 Canvas/SVG 是必要条件；
- 仅 `no-svg` 有效：SVG 路径动画是主要触发源；
- `no-backdrop` 有效：固定层与 backdrop 组合是主要触发源；
- `no-hover-effects` 有效：交互动画造成的合成层变化是主要触发源；
- 所有对照均无效：继续检查 Astro 客户端路由持久化、浏览器扩展、显卡驱动与 GitHub Pages 域名环境。
